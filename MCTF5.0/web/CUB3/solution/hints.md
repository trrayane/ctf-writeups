# Hints

## Hint 1: Understand the Keyboard Layout
The challenge uses keyboard shortcuts instead of standard Rubik's cube notation. Each key corresponds to a cube move. Try pressing the keys to understand how they affect the cube visualization.

## Hint 2: Learn the Key Mappings
The keys are organized by layer:
- **q/w** - Upper layer (U moves)
- **a/s** - Bottom layer (D moves)  
- **e/d** - Left column (L moves)
- **r/f** - Right column (R moves)
- **t/g** - Front face (F moves)
- **y/h** - Back face (B moves)

## Hint 3: Remember the Beginner's Method
Use the Layer-by-Layer method:
1. Solve the white cross
2. Solve white corners
3. Solve middle layer edges
4. Solve yellow cross
5. Solve yellow corners
6. Permute yellow corners

## Hint 4: Time Management
You have 10 seconds to submit the solution. The keystroke entry validates your moves server-side. Focus on efficiency!
